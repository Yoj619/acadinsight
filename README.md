# AcadInsight – Program Chair Dashboard

Analytics and decision-support dashboard prototype for BAT 405 (Analytics Application).
It combines Student and Faculty Portal data with SETE results for the BSIT Program Chair.

All figures are sample data created for the prototype, not real university records.

## Files
- `index.html` – the dashboard
- `data.js` – sample data (enrollment, class sections, SETE results)
- `d3.min.js` – chart library (D3 v7)
- `favicon.svg` – AcadInsight logo icon

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com: Add New → Project → import the repository → Deploy (no build settings needed).
